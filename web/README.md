# ProbCast web — pro UI (R1.0 slice)

The local research UI for ProbCast: _Ex-ante by construction._ It follows `docs/kb/06-architecture/ux-spec.md` v1.1 (binding for `web/`) and the API in `architecture.md` §8. Educational research tool. Not investment advice.

## Commands

```bash
cd web
pnpm install          # exact, pinned versions (see package.json)
pnpm dev              # http://127.0.0.1:5173 (localhost only)
pnpm build            # production build into dist/
pnpm preview          # serve dist/ on http://127.0.0.1:4173
pnpm typecheck        # tsc --noEmit (strict)
pnpm lint             # Biome (lint + format check)
pnpm format           # Biome, write fixes
pnpm test             # Vitest (unit, component, chart-builder, token and fixture tests)
pnpm fixtures         # regenerate the synthetic fixtures (seeded, byte-stable)
```

## Data source

- **Fixtures (default).** With `VITE_API_BASE` unset, every endpoint is served from `src/fixtures/*.json` (ticker `DEMO`, synthetic, seeded). Charts carry an `ILLUSTRATIVE` watermark.
- **Engine.** Set `VITE_API_BASE=http://127.0.0.1:8000` (e.g. in `web/.env.local`) and the client calls `${VITE_API_BASE}/api/v1/...`.
- **Fixture states.** In fixture mode, `?fx=` selects a state, also from the "Fixtures" menu at the bottom of the rail: `sealed` (default), `frozen`, `revealed`, `baseline_only`, `insufficient`, `stale`, `leakfail`, `empty`, `error`, `offline`, `integrity` (a payload that leaks holdout scores while sealed, to show the integrity block).
- The client is read-only. There is no freeze or reveal path anywhere (D-047).

## Routes (R1.0)

| Route               | Screen                                                                                                                                                                            |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/`                 | Home / Mission control: committee fan, readout, P(price higher) with base rates, scenarios, anchor sensitivity, latest verdicts, freshness, registered forecast, price and events |
| `/runs/:runId/:tab` | Run view: `overview` · `calibration` · `scores` · `robustness` · `manifest`                                                                                                       |
| `/committee/:tab`   | Committee: `forecast` · `attribution` (R1.0) and `scenarios` · `members` · `anchor` · `freeze` (read-only)                                                                        |
| `/leaderboard`      | Leaderboard, sorted by CRPSS vs the CAPM anchor, filters in the URL                                                                                                               |
| `/about/:page`      | `look-ahead` · `scoring` · `committee` · `glossary` · `data` · `disclaimer`                                                                                                       |

Global URL state: `?h=` (5 · 21 · 63 · 126 · 252 sessions, default 252) persists across navigation.

Keyboard: `1`–`5` horizon · `[` rail · `G H` / `G L` / `G M` / `G A` go to · `⌘K` go to… · `?` shortcuts · `V` table view of a focused chart · `←/→` fan cursor · `J/K` leaderboard rows · `I` or Enter provenance of a focused value · `Esc` closes.

## Honesty contracts (enforced in code and tests)

- `ForecastReadout` requires `interval80` and `interval95` by type and renders a blocked state if either is missing at runtime.
- Every skill value is rendered through `Skill`, which always carries an `EvidenceStrip` (grade, n_eff, trials, MDE, tilt where supplied); n_eff < 10 hides the value, 10–19 greys it.
- `hist_drift` is named only through `YardstickLabel` ("survivor-biased").
- While the holdout is sealed, any payload containing `sample: "holdout"` is refused by the query layer and the panel shows "Integrity check: holdout scores received while sealed. Not displayed."
- The median waterfall refuses to draw if the steps do not reconcile within 0.1 pp.
- Scenario labels read thresholds from the payload; the scenario set is fixed (< −15%, −15…+15%, > +15%).
- The disclaimer is a constant; `DisclaimerBar` has no text prop.

## Notes

- Charts: Apache ECharts only, modular imports, loaded per route. The fan bands are custom polygon series; the log price scale is a value axis over ln(price) with nice price ticks.
- Fonts are self-hosted (`@fontsource-variable/*`); KaTeX renders offline. No external requests.
- Not yet built: Playwright E2E/axe scans, the dev component gallery, the Committee "Ask" input (needs the exceedance endpoint, UXR1-12), and every R1.1/R1.2 screen (Data, Events, Idea lab, Analyzers, Report studio, Settings, time machine).
